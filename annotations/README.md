# Annotation increment

This directory contains the 100-image colored-obstacle and turn-focused increment used for the v3 model.

- `labelme_json/`: editable LabelMe polygon annotations
- `yolo_labels/`: matching YOLO segmentation labels
- Class `0`: traversable floor or track region
- Class `1`: obstacle

The referenced raw images are intentionally excluded from GitHub. The labels are retained so the annotation work, class definitions, and conversion results are version controlled.
