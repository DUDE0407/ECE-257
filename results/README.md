# Saved results

The current checkpoint was trained with 304 training images and evaluated with 76 validation images.

- `validation_metrics.json`: current v3 validation metrics
- `same_validation_comparison.json`: v2 and v3 checkpoints evaluated on the same 76-image validation split
- `results.csv` and `results.png`: per-epoch training history
- `confusion_matrix_normalized.png`: normalized validation confusion matrix

Metrics describe this dataset split only and should not be interpreted as final onboard-camera or complete-vehicle performance.
